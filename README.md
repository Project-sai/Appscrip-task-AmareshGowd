# Appscrip Task – Amaresh Gowd

This is a demo product listing page built using **Next.js** as part of the Appscrip frontend task.

## 🔧 Tech Stack

- React.js (via Next.js)
- HTML5 & CSS3 (No pre-built CSS libraries)
- Server-Side Rendering (SSR)
- SEO Optimization
- Responsive Design (Mobile & Tablet friendly)
- Hosted on Netlify

## 🚀 Live Demo

👉 [Live Site on Netlify](https://appscrip-smartshop.netlify.app/)

## 📁 Features

- Product listing grid layout
- Semantic HTML and accessible tags
- Clean code structure & naming conventions
- Responsive design using CSS Grid
- SSR-enabled with Next.js
- SEO enhancements (title, description, headings, alt text)

## 🧠 SEO Setup

- `<title>` and `<meta name="description">` for SEO
- Proper `<h1>` and `<h2>` usage
- Alt tags on all images
- Semantic HTML5 structure
